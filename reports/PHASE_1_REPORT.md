## 1. ما الذي فُحص في بيئة العمل
فُحصت البيئة فعليًا قبل أي تنفيذ (بلا افتراضات)، وكانت النتائج:

| البند | النتيجة الفعلية |
|---|---|
| نظام التشغيل | Linux x86_64 (حاوية عمل معزولة) — ليست محطة عمل رسومية |
| Blender | لم يكن مثبتًا كبرنامج؛ **لكن أمكن تشغيله فعليًا كوحدة `bpy` (Blender 5.0.1) بوضع headless عبر Python 3.11** بعد إنشاء بيئة افتراضية مخصصة |
| Unreal Engine 5 | **غير موجود إطلاقًا** (لا محرر ولا أدوات سطر أوامر) — لا يمكن إنشاء مشروع UE أو اختبار الاستيراد في هذه البيئة |
| وحدة معالجة الرسوميات (GPU) | **غير موجودة** (لا nvidia-smi ولا Vulkan) — يتعذر تشغيل محرر UE حتى لو ثُبّت |
| أدوات Sony PlayStation | **غير موجودة ولا يمكن وجودها هنا** — أدوات PS مرتبطة بتراخيص NDA ومحطات معتمدة (انظر §7) |
| Python / Node / git | متوفرة (Python 3.12 + بيئة 3.11 معزولة، Node 24، git 2.47) — استُخدمت لإنتاج الأصول والتحقق الآلي |
| مشاريع قائمة | **لا يوجد أي مشروع UE أو ملفات Blender سابقة** في مساحة العمل (تحقق بمسح `*.uproject` و`*.blend`) |
| القرص/الذاكرة | مساحة كافية لإنتاج الأصول (9.3GB حرة) وذاكرة 4.1GB كافية للوضع headless |

## 4. خطة خط الإنتاج Blender ← Unreal Engine 5
محددة تفصيلًا في `docs/TECHNICAL_PIPELINE.md`، وخلاصتها:
- **المقياس/الاتجاه:** 1 م = 100 uu؛ التأليف بواجهة -Y في Blender؛ تصدير FBX بإعدادات معيارية مُتحقق من إنتاجها فعليًا (`axis_forward=-Y`, `axis_up=Z`, `FBX_SCALE_UNITS`) — المخرجات FBX 7.4 ثنائية سليمة الترويسة.
- **بوابة المعايرة CAL-01:** أصل `TLS-ENV-001` (gnomon متعدد المواد — 5 فتحات فعلية: سهم أحمر +X، لوح أزرق -Y، هرم ذهبي +Z، جسم رمادي، قاعدة داكنة؛ قاعدة 1×1 م) + شخصية مرجعية 1.75 م — كلاهما **مُنتج فعليًا** وبانتظار الاستيراد داخل UE (غير ممكن هنا). *(تصحيح M0: العدد الفعلي للمواد 5 لا 4 — مطابق `manifest_calibration.json`؛ انظر تقرير M0 §2.5.)*
- **مصفوفة اختبارات الاستيراد IMP-01..04** (ثابت/هيكلي/أنيميشن/مواد) مع معايير نجاح رقمية، تُنفذ في M0 على محطة عمل، وبعدها **تُقفل الإعدادات** ويبدأ الإنتاج الجماعي.
- **سياسات:** تسمية موحدة (`tls_cat_nnn_name`)، سقوف مثلثات، سياسة Nanite للبيئات دون الشخصيات، حزم قوام ORM (R=AO/G=Rough/B=Metal)، هيكل عظمي أصلي 100%، تصادمات `UCX_`، git-LFS مع قفل ملفات.
- **أصغر مجموعة اختبار كاملة للخط:** 7 بنود (جدول §12 في الوثيقة) — اثنان منها أُنجزا فعليًا هنا.

## 5. خطة استهداف Windows ← macOS ← PlayStation
محددة في `docs/PLATFORM_STRATEGY.md`، وخلاصتها:
- **Windows أولًا:** DX12، الحد الأدنى 1080p/30 (GTX 1650)، الموصى بها 1440p/60 (RTX 3060)، فحوص PSO وAlt-Tab وHDR.
- **macOS ثانيًا:** Apple Silicon فقط (M1+) عبر Metal مع Lumen البرمجي؛ notarization+Hardened Runtime إلزاميان؛ مخاطر فجوة الميزات وأجهزة الاختبار موثقة.
- **PlayStation ثالثًا ورهين الترخيص — وبأقصى وضوح:** إعداد مشروع متعدد المنصات **لا يعني** إمكانية النشر على PlayStation؛ يتطلب PlayStation Partners واعتماد concept وdev kits والالتزام بـ TRC وتصنيف عمري وشهادة متجر؛ **لا شيء من ذلك متاح في هذه البيئة**، وأي قيمة تقنية PS5 في وثائقنا موسومة كتقدير يُعاد ضبطه بالأدوات الرسمية.
- **حرّاس عابرون للمنصات** (قائمة §2): Enhanced Input فقط، لا مسارات مطلقة، ميزانية ذاكرة/إطار موحدة، وكل إضافة UE تُفحص توافقها على المنصات الثلاث قبل الدمج.

## 6. أول مرحلة تنفيذية قابلة للاختبار
**M0 — التأسيس ومعايرة خط الإنتاج** (4–6 أسابيع على محطة عمل Windows مناسبة؛ التفصيل في `docs/MILESTONE_PLAN.md`):
1. مستودع git/LFS + مشروع UE5 مقفل الإصدار + ربط CI بـ `tools/validate_project.py` (الفاحص يعمل الآن وجاهز للربط).
2. تنفيذ مصفوفة IMP-01..04 وCAL-01 داخل UE بلقطات موثقة — **بوابة بدء M1 رسميًا**.
3. شخصية blockout تمشي بـ Enhanced Input (لوحة مفاتيح/فأرة + ذراع) في غرفة اختبار مضاءة بـ Lumen.
4. معايير القبول رقمية: قياس gnomon داخل UE بتسامح ≤0.5%، اتجاه بلا دوران يدوي، 60fps على المواصفات الموصى بها.
**ما أمكن اختباره في هذه البيئة نُفذ فعلًا:** توليد أصول المعايرة بـ Blender 5.0.1 headless (نجحت فحوصات الأبعاد الذاتية: 1.75 م بالضبط) + فاحص سلامة المشروع (النتيجة أدناه).

## 7. الأدوات أو الصلاحيات أو المعلومات الناقصة
| الناقص | الأثر | المطلوب |
|---|---|---|
| Unreal Engine 5 + GPU | لا إنشاء مشروع ولا اختبار استيراد هنا | محطة عمل Windows بمعايير الموصى بها (الميلستون M0) |
| ترخيص Sony PlayStation Partners + dev kit | مسار PS معلق بالكامل | بدء إجراء الانضمام فورًا (مسار طويل خارجي) |
| شهادة Apple Developer | تعذّر فحص notarization الفعلي لاحقًا | تسجيل مبكر قبل M4 |
| فريق بشري (فنان/كاتب/صوت) | الوثائق جاهزة لكن الإنتاج يحتاج بشرًا | تجنيد نواة قبل M1 |
| أداء صوتي ويلزي | ميزانية ومؤدون | قرار M3 |
| قرار المتجر (Steam/Epic) | يؤجل بلا ضرر إلى M4 | عرض الأسعار عند البيتا |
| ملاحظة: صلاحيات هذه البيئة | لا صلاحية لتثبيت برامج رسومية كاملة أو واجهات | كُلّف بالتنفيذ داخل حدود المتاح — ولم يُدَّعَ غير ذلك |

## 8. المهمة التالية التي يجب تنفيذها
1. **اعتماد حزمة الوثائق هذه** (خاصة قاموس الأسماء وأسوار النطاق) — أي تعديل يبدأ من `GAME_BIBLE.md` ثم يتدفق.
2. تجهيز محطة عمل Windows (معايير "الموصى بها" في وثيقة المنصات) وتثبيت UE5 نسخة مقفلة + Blender.
3. إنشاء `TLS.uproject` + مستودع git مع LFS وربط CI بفاحص السلامة المرفق.
4. تنفيذ IMP-01..04 + CAL-01 داخل UE بلقطات موثقة — **هذه بوابة بدء الإنتاج**.
5. فورًا وبالتوازي: فتح ملف انضمام PlayStation Partners (لا ينتظر اكتمال M0).
