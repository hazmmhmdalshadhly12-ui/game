# M3.6 — Edmund Vale 艺术质量升级 — 实测报告

> **分支** `feature/m3-6-edmund-quality-upgrade`（堆叠于 M3.5 `feature/m3-5-edmund-validation-fixes` 之上）。
> 本报告只含实测数字（`reports/character-review/Edmund/data/` 的 5 个 JSON 全部由脚本从最终 .blend / FBX 现场测得），每个视觉结论都附对应渲染图。**UNREAL IMPORT NOT TESTED**（环境无 UE 5.4，同 M2/M3.x 阻断项，不变）。

## 0. 定位与诚实边界

M3.5 把 Edmund 修到"0 几何缺陷 + rig 健康"，但渲染暴露出它离 M3.x 指令的目标差距巨大：头发是放射状黑色硬片、眼睛是贴纸般的巨型蓝虹膜、胡茬爬到眼眶、全身上下几乎一种灰色。M3.6 是一**纯程序化（Blender 5.0.1 headless Python）**的艺术质量升级——没有手雕、没有外部素材、没有扫描。因此**不声称**达到"AAA/照片级"；本次交付的诚实定位是：**结构正确、历史着装可读、渲染干净的程式化角色**，其全部改进可由仓库内脚本确定性复现。

## 3. "方块碎屑"排查记录（对后续梳理有价值的负结果）

渲染上头皮出现规则暗色矩形（自 M3.5 就存在，M3.6 初期更明显）。逐项隔离：alpha 材质接线 ✓ 正常（隔离四边形任何尺度干净）、UV ✓ 正确（逐循环转储）、EdgeSplit ✗ 去除后仍在、Subsurf ✗ A/B 相同、阴影 ✗ `visible_shadow=False` 后仍在、高光 ✗ spec=0.06 后仍在、并行传输修折叠 ✗ 仍在、BVH 推出 ✗ 仍在、缩小采样 ✗ 远距四边形干净。**红材质替换后碎屑消失** → 定性为材质/alpha 管线与角色场景的某种交互，8 次实验未能最终定位 → 弃用 alpha（几何锥形收窄路线，零碎屑）。所有隔离渲染保存在工作目录 `renders_iso_*` / `ab_*` / `red_material_test.png`（不入库，报告为证）。
