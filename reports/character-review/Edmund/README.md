# M3.5 — إصلاح وتحقق أول شخصية حقيقية: إدموند ڤيل — THE LAST SIN: The Sin-Eater

> التاريخ: 2026-10-24 · الفرع: `feature/m3-5-edmund-validation-fixes` (فوق `feature/m3-4-edmund-character` @ e951b95)
> التنفيذ: **Blender 5.0.1 headless** (نفس إصدار أصول المعايرة) على Linux بلا GPU — Cycles CPU + OpenImageDenoise.
> هذه المرحلة **إصلاح وتحقق** لنموذج M3.4 القائم — ليست شخصية جديدة، ولم تُلمس أصول المعايرة الأصلية.

## ما الذي أُصلح فعليًا (قياس ورندر، لا ادعاء)

1. **حسم تعارض القياسات بأدلة**: إعادة البناء بالسكربتات الأصلية أعادت إنتاج `build_stats.json` حرفيًا (22,457/39,408) — جدول تقرير M3.4 كان هو غير الصحيح. **2,032 رأسًا شاردًا** (كرات جفون غير مستخدمة + بقايا حذف أوجه) حُددت بعناقيد ثم حُذفت من المصدر → **0 شاردة / 0 non-manifold / 0 NaN** في كل المجسمات الـ15 بعد إعادة الفتح.
2. **عيب الجذر: أذنان متجمدتان + شعر/لحية متجمدة**: رؤوس كانت تحمل مجموعات مساعدة غير عظمية (`scalp/beard/brow` لأخذ عينات جذور الشعر) فلا تتبع الهيكل إطلاقًا — **90,949 رأسًا أُصلحت** (534 جسم، 228 حذاء، 12 حاجب، 58,875 شعر، 31,200 لحية). بعد الإصلاح: دوران الرأس شدّه **من 15.75x إلى 1.075x**.
3. **كشط تلوث عظام العين**: 5,020 رأسًا في الجسم/الياقة/القميص كانت تسحب أوزان عظام العين — العظام الآن تقود مقالع العين فقط.
4. **إصلاحات معطف مرئية**: تغطية الكتفين (كانت الدلتويد عارية فوق الأكمام)، مقدمة مغلقة بخط أزرار تاريخي (كانت مفتوحة 114°)، منديل الرقبة فوق الياقة (كان مدفونًا داخلها)، حقيبة على الورك الأيسر التشريحي.
5. **وجه/شعر/خامات محسّنة**: عيون أكبر بقرنية رطبة وقزحية أوضح، شفاه أاملكم بلا لحية فوقها، أنف أعرض (أُزيل عيب "نجمة الأنف" المكتشف بالرندر)، شعر يلتصق بالجمجمة، جلد بلا تنقيط اليدين، حذاء مصقول.
6. **تصحيحات عقد**: تسمية L/R أصبحت تشريحية (اليسار = +X)، بقعة الحبر على اليد اليسرى الحقيقية (CHR-01)، `mesh_smooth_type='OFF'` وفق TECHNICAL_PIPELINE، الحذاء ملامس الأرض (ارتفاع مقاس **1.7877م**).

## الأرقام المقاسة من الملف النهائي (بعد الحفظ وإعادة الفتح)

- **الميش**: 20,605 رأسًا / 39,760 مثلثًا (12 مجسمًا) + شعر 53,168 مثلث + لحية 20,800 + حواجب 3,440 (بطاقات optional)
- **هندسة**: 0 شاردة / 0 non-manifold / 0 NaN / 0 رؤوس بلا أوزان (فحص مستقل `data/inspect_final.json`)
- **rig**: 65 عظمة، 9 اختبارات تشوه (مرفق/رأس/عمود/فخذ/كتف/معطف-كتف/معطف-فخذ/مشي-جسم/مشي-معطف) — أقصى شد 1.35 ووضعية مشي 1.62، **0 NaN**
- **FBX** (عقد `-Y/Z` + `FBX_SCALE_UNITS` + `OFF`): إعادة استيراد بجلسة فارغة → 14,191 + 6,414 = **20,605 رأسًا بالضبط** و65 عظمة في كلا الملفين — لا فقدان هندسة
- **المدققات**: validate_project 79/79 + validate_narrative 43/43 + validate_unreal_scaffold 70/70 + test_fbx_roundtrip (أصول المعايرة) 16/16
