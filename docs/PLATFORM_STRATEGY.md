# PLATFORM_STRATEGY — خطة استهداف Windows ← macOS ← PlayStation
> **v0.1 — 22 أكتوبر 2026** | مبدأ الحوكمة: **PC-first دون أسر تقني** — كل قرار يجب أن يُسأل: "هل يجعل نقل اللعبة لاحقًا أصعب بلا ضرورة؟"

## 1. مبدأ الترتيب والسبب
1. **Windows أولًا:** حلقة التطوير الكاملة (Blender+UE+أدوات) على متناول الفريق، قاعدة اللاعبين الأوسع لألعاب التحقيق، وأسرع دورة اختبار.
2. **macOS ثانيًا:** جهد نقل حقيقي لكن محدود الكلفة إن حُكمت القرارات مبكرًا (Metal، Apple Silicon، التوثيق).
3. **PlayStation ثالثًا ورهين الترخيص:** **وجود مشروع متعدد المنصات في UE لا يعني إطلاقًا إمكانية النشر على PlayStation** — انظر §5.

## 2. القرارات المعمارية العابرة للمنصات (Cross-Platform Guardrails)
| المجال | القرار | يمنع |
|---|---|---|
| الرسوم | Lumen (SW+HW) مع إعدادات قابلة للتخفيف، TSR للترشيح، Virtual Shadow Maps | الاعتماد الحصري على ميزات NVIDIA/DX12 (مثل Lumen HW فقط) |
| الإدخال | **Enhanced Input** فقط: خرائط إدخال موحدة KB+M/DualSense/Xbox + كشف تلقائي للأيقونات | إدخال قديم (Input)، أو تجسيد أزرار Xbox داخل منطق اللعبة |
| الواجهة | تركيز كامل بالمذاهب + مناطق أمان TV + خط بديل عند غياب محارف | قوائم لا تُقاد بذراع التحكم |
| المسارات | كل قراءة/كتابة عبر FPlatformFile/GamesSave APIs | مسارات مطلقة أو %USERPROFILE% |
| الخيوط | انضباط ميزانية 16.6ms حتى على PC المتوسطة (لا "متعدد الخيوط لأن PC قوي") | اعتماد عدد أنوية مرتفع |
| الذاكرة | ميزانية < 11GB RSS للحزم داخل اللعبة منذ M1 | أصول بلا سقوف |
| الإضافات | مراجعة كل إضافة UE: هل مدعومة رسميًا على المنصات الثلاث؟ | إضافات Windows-Only |
| التوطين | خط أنابيب نصي معزول (جداول) من اليوم الأول | نصوص داخل Blueprint صلبة |
| الصوت | MetaSounds حيث أمكن مع بدائل تعمل عبر المنصات | ترتيبات معالجة حصرية لمنصة |

## 3. Windows (الإطلاق الأول)
| البند | التفصيل |
|---|---|
| API الرسوم | DirectX 12 (RHI)؛ Vulkan غير مستهدف على PC |
| الحد الأدنى | 1080p/30fps إعدادات منخفضة: CPU رباعي النواة من 2019 (مثل Ryzen 3 1200/i5-7400)، 8GB RAM (12GB موصى)، GPU GTX 1650/RX 6500، 20GB تخزين |
| الموصى بها | 1440p/60fps إعدادات عالية: سداسي النواة 2022، 16GB RAM، RTX 3060/RX 6600 |
| العليا | 4K/60 مع Lumen HW: RTX 4070+، 32GB RAM |
| شاشات | نافذة/ملء شاشة/بلا حدود؛ HDR اختياري (تدرج لوحة CDL المشمعة!) |
| التوزيع | رقمي؛ قرار المتجر (Steam و/أو Epic) في M4 بعد جولة عروض — لا التزام مبكر |
| Steam Deck | هدف "قابل للعب" اختياري لطيف: خرائط إدخال جاهزة أصلًا، ووضع أداء 800p/30 — يُقيَّم في M5 |
| فحوص خاصة | PSO Precaching (منع اهتزاز أول مشهد)، إعدادات VSync/معدل غير محدود، سلوك Alt-Tab، دعم مقياس DPI للنصوص العربية عند التوطين لاحقًا |

## 4. macOS
| البند | التفصيل |
|---|---|
| الاستهداف | **Apple Silicon فقط** (M1 فأحدث) — أجهزة Intel Mac **غير مستهدفة** (توافقها مع إصدارات UE الحديثة منتهٍ/منتهي قريبًا وأداؤها غير كافٍ للعبة Lumen) |
| API الرسوم | Metal 3؛ **Lumen وضع البرمجيات (SW)** هو الخط الأساس (لا اعتماد على تتبع أشعة عتادي)؛ إعدادات ظلال مخففة؛ TSR عامل مشترك |
| الأداء المستهدف | M1: 1080p/30 (منخفض-متوسط)؛ M2/M3 Pro: 1440p/30-60 (متوسط)؛ Max: 1440p/60 (عالي) |
| النظام | macOS 13+ عند الإطلاق (يُعاد تقييم الرقم في M5) |
| التوزيع والتوقيع | **Notarization + Hardened Runtime إلزاميان** خارج Mac App Store؛ شهادة مطور Apple (Apple Developer Program) — بند ترخيص وميزانية مستقل يجب **البدء به مبكرًا** (يستغرق أيامًا لا دقائق) |
| الإدخال | KB+M أساس؛ دعم أذرع PlayStation/Xbox عبر GameController framework — أيقونات تلقائية |
| مخاطر موثقة | (أ) فجوة ميزات UE على Metal (إضافات/معالجات تصادم أحيانًا) — كل إضافة تُفحص توافقها Mac في M2؛ (ب) اختلاف إدارة الذاكرة الموحدة (سقوف texture budget أضبط من Windows)؛ (ج) صعوبة أجهزة الاختبار: مصفوفة شرائح M1/M2/M3 (قاعدة/Pro/Max) تُستأجر أو تُقاس على أقرب جهازين ثم تُوسَّع |
| قرار البناء | Universal2 غير مستهدف (x86_64 مهمل) — بناء arm64 نقي |

## 5. PlayStation — الحقيقة التنظيمية كاملة (بلاغ إلزامي)
> **لا يمكن — مطلقًا — بناء أو تشغيل أو حتى فتح أدوات PlayStation من دون العلاقة الرسمية مع Sony.** هذه البيئة لا تملك ولا يمكن أن تملك أدوات PS حتى مع الترخيص (اتفاقيات NDA تربط الأدوات بمحطات عمل معتمدة).

الطريق الرسمي المطلوب (يبدأ مبكرًا لا في النهاية):
1. **الانضمام إلى PlayStation Partners** (portal الرسمي) والتسجيل كناشر/مطور — يحتاج كيانًا قانونيًا وعنوانًا وضمانات مالية.
2. **اعتماد المشروع "concept"** قبل أي عمل تقني PlayStation.
3. **الحصول على dev kits** (شراء/إيجار عبر Sony) — لا تُباع للمستهلكين وأسعارها سرية بموجب NDA.
4. الالتزام بـ **TRC** (Technical Requirements Checklist): من الإدخال (أيقونات زر الدائرة/المثلث، توهج الخلفية عند السكون) إلى السكون (Rest Mode) والحفظ السحابي وحدود التحميل.
5. **تصنيف عمري (PEGI/ESRB عبر IARC)** وبيانات المتجر وضمانات الجودة قبل مراجعة الشهادة (cert).
6. **ملاحظة تنفيذية مهمة:** كل مواصفات PS5 التقنية أدناه **تخمين هندسي معقول** مبني على معرفة عامة منشورة — التحقق الفعلي يبدأ حين يُفتح باب الأدوات الرسمية؛ ولهذا تُدار كل "قيم PS5" في ملف واحد قابل للتعديل (`06_Build/PS5_targets.md` مخطط) لا مبعثرة في التصميم.

أهداف الأداء المبدئية (تُعاد معايرتها بالأدوات الرسمية):
| الوضع | الهدف |
|---|---|
| الجودة | 4K (CB) / 30fps، Lumen SW كامل |
| الأداء | 1440p→4K بـ TSR / 60fps، إعدادات مخففة |
| DualSense | لمسات haptics للفانوس/صفحات السجل (بعدوى مقيّضة)؛ زر R2 بمقاومة متغيرة عند رفع الفانوس — إضافة لطيفة لا شرط لعبي |

## 6. مصفوفة الاختبار لكل منصة (تُفتح تباعًا مع الميلستونات)
| المرحلة | Windows | macOS | PlayStation |
|---|---|---|---|
| M0–M1 | حلقة كاملة على الحد الأدنى والموصى | فتح مشروع ونافذة تحرير فقط (توافق بيانات) | — |
| M2 | اختبار أنظمة + حفظ/تحميل | بناء تجريبي داخلي arm64 | (إن اكتمل الترخيص: تهيئة مشروع على dev kit أولي) |
| M3 | محتوى كامل + أداء | توافق الأصول/الذاكرة على M1/M2 | تقارير توافق أولية إن توفرت أدوات |
| M4 | Beta + PSO + دعم GPU الواسع | Beta Mac + notarization تجريبي | إن وُجد: تقييم TRC مبكر |
| M5 | Candidate + إصدار | Candidate + إصدار | (مسار رهن الترخيص — قد ينزاح لموجة إصدار لاحقة) |

## 7. قواعد قرار "هل هذا يضر النقل؟" (Checklist لكل ميزة جديدة)
1. هل تستخدم API نظام واحد؟ → كبّسها خلف طبقة خدمة داخلية.
2. هل تربط أداءها بعتاد PC العالي؟ → اختبر على هدف الدنيا أولًا.
3. هل تعتمد إدخالًا ماوسيًا دقيقًا (بلا بديل ذراع)؟ → صمم بديلًا قبل الدمج.
4. هل تنتج نصًا صلبًا داخل الكود/البلوبرنت؟ → جدول نصوص.
5. هل تحتاج إضافة غير مدعومة على إحدى المنصات الثلاث؟ → استبدال أو عزل بخاصية قابلة للإطفاء.
