# References — THE LAST SIN

حزم المراجع البصرية الحقيقية (Reference Research Packs) المطلوبة قبل نحت أي أصل.

## البنية
- `characters/` — تشريح جمجمة/وجه/أذن/يد + بورتريهات القرن 19 + تجاعيد
- `clothing/` — معاطف وصديريات 1840s + أزياء ويلزية + أحذية + أثواب رجال دين
- `architecture/` — كوخ ST Cynog الحقيقي في ويلز + جدران جافة + أسقف أردواز + كنائس ريفية + حانات
- `props/` — فوانيس + سجلات رعية + مفاتيح + أطباق
- `materials/` — خامات: حجر + طحلب + بلوط + تويل + جلد

## القواعد
- كل صورة موثقة في `reference_manifest.csv`: الملف، المصدر (رابط Wikimedia Commons)، الرخصة، الفنان، تاريخ الاطلاع، الاستخدام المقصود.
- الرخص: 12 Public domain + 11 CC0 + الباقي CC-BY/CC-BY-SA — كلها تسمح بالاستخدام المرجعي.
- **الاستخدام مرجعي فقط** (فهم النسب والمواد والفترة) — الأصول المنتجة أصلية ولا تُوزع هذه الصور داخل اللعبة.
